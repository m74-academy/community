# Refreshers

Rusty on a skill the course assumes? Use these before or during the course. Pick one per topic; you don't need all of them.

## Python

**Quick syntax**

- [Learn Python in Y minutes](https://learnxinyminutes.com/python/): one annotated page covering the whole language.

**Official documentation**

- [The Python Tutorial](https://docs.python.org/3/tutorial/): the official guided tour, from basics to modules and classes.
- [Python documentation](https://docs.python.org/3/): language reference and standard library, for looking things up.

**Video**

- [Learn Python - Full Course for Beginners](https://www.youtube.com/watch?v=rfscVS0vtbw) (freeCodeCamp)
- [Python Full Course for Beginners](https://www.youtube.com/watch?v=_uQrJ0TkZlc) (Programming with Mosh)

## Git and GitHub

**Official documentation**

- [Pro Git](https://git-scm.com/book): the free official book. Chapters 1-3 cover everything the course needs.
- [Git reference](https://git-scm.com/docs): manual page for every command, for looking things up.
- [GitHub: About Git](https://docs.github.com/en/get-started/using-git/about-git): short intro to Git and how GitHub fits in.

**Practice**

- [Learn Git Branching](https://learngitbranching.js.org/): interactive visual exercises for commits, branches, and merges.
- [GitHub Skills](https://skills.github.com/): short hands-on courses inside GitHub.

**Video**

- [Git and GitHub for Beginners - Crash Course](https://www.youtube.com/watch?v=RGOj5yH7evk) (freeCodeCamp)
