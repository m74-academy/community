# M74 Academy community

This repository hosts the organization's [Discussions](https://github.com/orgs/m74-academy/discussions) and the course-wide setup guides. Lessons and assignments live in each module's repository.

## Guides

1. [Install uv and Git](guides/install-uv-and-git.md)
2. [VS Code or the terminal?](guides/vscode-and-terminal.md)
3. [Fork, clone, and set up a module](guides/fork-clone-setup.md)
4. [Read, edit, and check a lesson](guides/lesson-loop.md)
5. [Get course updates without losing your work](guides/course-updates.md)

## Discussion categories

- **Announcements** — course releases and schedule notes, posted by instructors.
- **Q&A** — questions about lessons, assignments, and tools; mark the answer that solved it.
- **Module 1** — anything specific to Module 1 and its capstone.
- **Feedback** — ideas to improve the course.

Follow the [code of conduct](https://github.com/m74-academy/.github/blob/main/CODE_OF_CONDUCT.md). Don't post solutions to assignments or capstones.
