# M74 Academy guides

Public reference guides for [M74 Academy](https://github.com/m74-academy) courses: set up your computer, learn the Git and Python you need, and understand how a lesson works. Lessons and assignments live in each module's repository, and each module has its own Discussions.

## Set up your computer

Do these once, in this order.

1. [Install the software](guides/install-uv-and-git.md): VS Code, `uv`, Git, GitHub CLI, and the `academy` command.
2. [Set up a module](guides/fork-clone-setup.md): fork, clone, install the project, and fix the remotes of an existing clone.
3. [Use VS Code for the course](guides/vscode-and-terminal.md): folders, terminals, and common problems.

## Learn the course

- [Course overview](guides/course-overview.md): what the Academy teaches and what each module builds.
- [How the course works](guides/how-the-course-works.md): lessons, Core and Gold, labs, and the capstone.
- [Read, edit, and check a lesson](guides/lesson-loop.md): the loop you repeat in every lesson.

## Refresh your skills
