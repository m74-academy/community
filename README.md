# M74 Academy community

This repository hosts the organization's [Discussions](https://github.com/orgs/m74-academy/discussions). It holds no course material.

Categories:

- **Announcements** — course releases and schedule notes, posted by instructors.
- **Q&A** — questions about lessons, assignments, and tools; mark the answer that solved it.
- **Module 1** — anything specific to Module 1 and its capstone.
- **Feedback** — ideas to improve the course.

Follow the [code of conduct](https://github.com/m74-academy/.github/blob/main/CODE_OF_CONDUCT.md). Don't post solutions to assignments or capstones.
