# M74 Academy community

This repository hosts the organization's [Discussions](https://github.com/orgs/m74-academy/discussions) and the course-wide guides. Lessons and assignments live in each module's repository.

## Get started

1. [Set up your computer](guides/install-uv-and-git.md), once.
2. Open [Module 1](https://github.com/m74-academy/module-1) and follow its **Start here**.
3. [Read, edit, and check a lesson](guides/lesson-loop.md).

## More guides

- [Use VS Code for the course](guides/vscode-and-terminal.md)
- [Fork, clone, and set up a module, step by step](guides/fork-clone-setup.md)
- [Get course updates without losing your work](guides/course-updates.md)

## Discussions

- **Announcements**: course releases and schedule notes, posted by instructors.
- **Q&A**: questions about lessons, assignments, and tools; mark the answer that solved it.
- **Ideas**: suggestions to improve the course.

Follow the [code of conduct](https://github.com/m74-academy/.github/blob/main/CODE_OF_CONDUCT.md). Don't post solutions to assignments or capstones.
